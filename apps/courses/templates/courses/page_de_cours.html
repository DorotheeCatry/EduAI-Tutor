{% comment %} La colonne de droite : Koda en haut, une cellule Python en bas. Compétence visée : C17 (épreuve E4) Compétences concernées : C10 (E3) ; C13 (E3) — accessibilité, sécurité Elle proposait trois boutons d'enrichissement. Ils supposaient qu'un apprenant sait, avant de lire, ce qu'il ne comprendra pas — alors qu'une question naît en lisant, et qu'elle est rarement l'une des trois. Deux zones, donc, et elles répondent à deux gestes différents : demander, et essayer. La cellule Python n'appelle aucun service facturé : elle s'exécute sur le serveur, dans l'exécuteur restreint des exercices. {% endcomment %}
{% comment %} Koda lui-même, et non une icône de bulle. Compétence visée : C17 (épreuve E4) Choix : reprendre exactement la planche et les dimensions du panneau flottant. Motivation : c'est le même interlocuteur ; le voir changer d'apparence selon la page laisserait croire à deux assistants différents. Le script de la page pilotait déjà ses états — « réfléchit » pendant l'attente, « parle » à la réponse — mais aucun élément `data-koda` n'existait ici et `koda.js` n'y était pas chargé : les appels tombaient dans le vide. Écrit, atteignable, jamais exécuté : le troisième motif d'incident du projet. `aria-hidden` : le titre voisin annonce déjà de qui il s'agit. {% endcomment %}
