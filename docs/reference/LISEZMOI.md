# Documents de référence

Compétence visée : C19 (épreuve E4) — traçabilité

Ce dossier réunit les documents **reçus**, non produits par le projet : le
référentiel de certification et les schémas d'épreuves fournis par l'organisme.

Ils sont versionnés pour que le dépôt soit lisible sans pièce jointe extérieure,
et séparés de `docs/decisions/` — qui ne contient que les décisions prises sur ce
projet — pour qu'un lecteur distingue d'un coup d'œil ce qui est imposé de ce qui
est choisi.
